# Security Policy

## Versioni supportate

Le correzioni di sicurezza vengono applicate alla versione stabile piu recente.

## Segnalare una vulnerabilita

Non aprire una issue pubblica con dettagli sfruttabili, chiavi, indirizzi IP o
configurazioni reali. Dopo la pubblicazione su GitHub, usa la segnalazione
privata di vulnerabilita del repository, se abilitata; altrimenti contatta in
privato il proprietario del repository tramite il suo profilo GitHub.

Includi passi per riprodurre il problema, versioni di client e server coinvolte
e il possibile impatto. Riceverai conferma e aggiornamenti sul rimedio.
